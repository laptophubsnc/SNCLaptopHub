## GitHub Pages

1. Create a new empty GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, `.gitignore`, and `assets/`.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.

## Important
